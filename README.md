# Tools

Development tools from Noldova.

## Packages

None yet. The first two run the steps of a build and release pipeline:
`@noldova/tools.pipelines`, the steps that work the same on any host, and `@noldova/tools.pipelines.github`, which runs them on GitHub Actions.
Each package will be published on npm under its own name.
